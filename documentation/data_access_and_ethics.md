# Availability, privacy, and rights

- **Current published dataset:** [BnPostDuo, Mendeley Data Version 2](https://data.mendeley.com/datasets/6678wc3bs7/2) — **4,708 records**.
- **Previous dataset version:** [Mendeley Data Version 1](https://data.mendeley.com/datasets/6678wc3bs7/1) — 4,800 records.
- **Public image release:** the original Facebook images are **not included in the public Mendeley or GitHub packages**.
- **Image access requests:** researchers may complete the [Google Form](https://forms.gle/wKSdaqRD4rpT5T6f7). The team reviews requests and, only for approved requests where sharing is authorized, provides a restricted Google Drive link privately.
- **Released derived fields:** captions, raw OCR, curated image text, category labels, pHash and image dimensions.

The dataset was constructed using publicly accessible Facebook pages and groups during 2025–2026. Publicly viewable content is not automatically free of copyright, privacy, or platform restrictions. A perceptual hash cannot provide a substitute for the original image. Conventional image-based and vision-language experiments require separate lawful access to the original images. The request form is not a guarantee of access; any restricted image delivery must comply with third-party rights and applicable obligations.

Check the official Mendeley Data record for the data license applicable to the **specific version** downloaded. Do not interpret a GitHub code or documentation license as permission to redistribute third-party Facebook content.

The authors' manuscript reports privacy-related handling, but this repository does not independently audit the original sources or establish any third-party redistribution permissions.

For the full procedure, see [Image access requests](image_access.md).
