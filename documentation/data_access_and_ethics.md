# Availability, privacy, and rights

- **Published data repository:** [BnPostDuo, Mendeley Data Version 1](https://doi.org/10.17632/6678wc3bs7.1).
- **Version 2:** a deduplicated 4,708-record export was prepared locally; add the published Mendeley Data Version 2 DOI when available.
- **Image release:** original Facebook images are **not redistributed**.
- **Released derived fields:** captions, raw OCR, curated image text, category labels, pHash and image dimensions.

The dataset was constructed using publicly accessible Facebook pages and groups during 2025–2026. Publicly viewable content is not automatically free of copyright, privacy, or platform restrictions. A perceptual hash cannot provide a substitute for the original image. Conventional image-based and vision-language experiments require separate lawful access to the original images.

Check the official Mendeley Data record for the data license applicable to the **specific version** downloaded. Do not interpret a GitHub code or documentation license as permission to redistribute third-party Facebook content.

The authors' manuscript reports privacy-related handling, but this repository does not independently audit the original sources or establish any third-party redistribution permissions.
